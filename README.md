# 🐧 LinuxConfig

An ongoing project combining a collection of Bash scripts to bootstrap a newly-installed Linux instance with all required apps, configurations, and dotfiles. Features a modular design to support future expansion.

Feel free to take inspiration from or fork/clone this project and adjust it to your own setup, though note that this project is more so me documenting my own setup rather than a catch-all script for anyone to download and run without modification. **Adjustments are needed, use this as a starting point rather than an easy automation script to download and use.**

⚠️ This project is currently a work-in-progress. It includes known issues and lacks explicit documentation to facilitate comfortable reuse by others.
